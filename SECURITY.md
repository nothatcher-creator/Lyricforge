# Security Policy

Please do not post secrets, API keys, tokens, private endpoints, personal data, or an exploit payload containing sensitive information in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use **Private vulnerability reporting** from the repository Security area. If that option is unavailable, open a minimal public issue saying that you need a private contact path; do not include sensitive exploit details in that issue.

When reporting a vulnerability, include the affected LyricForge version, browser/platform, reproducible impact, the smallest safe reproduction you can provide, and whether the issue affects the GitHub Pages build or only a local/custom deployment.

There is no promised response SLA in this repository. Supported releases should be treated conservatively: verify whether the issue reproduces on the current deployed version before reporting it as current.

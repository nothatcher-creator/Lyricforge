# Changelog

## v0.3.7 — Preset Library & Professional Editor Tools

- Added portable, validated `.lyricpreset` import/export and IndexedDB-backed installed presets.
- Added first-party downloadable preset catalog with Factory / Installed / Library views.
- Added direct canvas selection controls, resize/rotate, crop, flip, grouping, lock, layer order and style copy/paste.
- Added timeline Select/Razor tools, split, trim, ripple delete, fades, labels, track height and keyframe toggle.
- Added crop/flip/fade preview/export render parity and normalized backward-compatible model fields.
- Published normal canonical source/tests/docs instead of relying on deployment fragments.

## v0.3.6 — Creative Expansion

- Expanded factory presets, text effects, whole-video effects, fonts and contextual preview gestures.
- Preserved mobile/portrait editor behavior and verified deployment integrity.

## v0.3.5 — Portrait Scrolling Fix

- Improved scrollability and reachability of portrait tool docks and bottom sheets.

## v0.3.4 — Portrait Editor

- Added Android-focused portrait layout and mobile editor navigation.
